# ממשק משתמש ויזואלי למשחק קטאן

## תיאור
ממשק משתמש גרפי מלא למשחק "המתיישבים של קטאן" שבנוי ב-React + TypeScript עם Vite.

## תכונות

### 🎮 לוח משחק אינטראקטיבי
- **19 אריחים משושים** עם גרפיקה ייחודית לכל סוג משאב (יער, חיטה, צמר, עפרות, חומר, מדבר)
- **מספרי קוביות** על כל אריח עם נקודות הסתברות
- **שודד** שמוצג על האריח הרלוונטי
- **54 קודקודים** אינטראקטיביים לבניית כפרים וערים
- **72 צלעות** אינטראקטיביות לבניית כבישים
- **9 נמלים** מסביב ללוח עם אייקונים מתאימים (3:1 כללי, 2:1 ספציפי)

### 👥 תצוגת שחקנים
- **פאנלים משני צידי המסך** המציגים את פרטי השחקנים
- **צבעים ייחודיים** לכל שחקן
- **נקודות ניצחון** בולטות
- **סטטיסטיקות**: מספר משאבים, כפרים, ערים, כבישים, קלפי פיתוח ואבירים
- **חלון משאבים**: לחיצה על כרטיס שחקן פותחת חלון מפורט עם כל המשאבים

### 🎯 פעולות במשחק
- **הטלת קוביות** עם אנימציה וחלוקת משאבים
- **בניית כבישים** - לחיצה על צלע
- **בניית כפרים** - לחיצה על קודקוד
- **שדרוג לעיר** - לחיצה על כפר קיים
- **ניהול תורות** עם כפתור "סיים תור"

## התקנה והרצה

### דרישות מוקדמות
- Node.js (גרסה 16 ומעלה)
- npm או yarn

### התקנה
```bash
npm install
```

### הרצה במצב פיתוח
```bash
npm run dev:client
```

הממשק יהיה זמין בכתובת: http://localhost:3000

### בניית גרסת ייצור
```bash
npm run build:client
```

### תצוגה מקדימה של גרסת ייצור
```bash
npm run preview
```

## מבנה הפרויקט

```
client/
├── components/          # קומפוננטות React
│   ├── GameBoard.tsx   # לוח המשחק המרכזי
│   ├── HexTile.tsx     # אריח משושה בודד
│   ├── VertexPoint.tsx # קודקוד (כפר/עיר)
│   ├── EdgeLine.tsx    # צלע (כביש)
│   ├── PortIndicator.tsx # נמל סחר
│   └── PlayerPanel.tsx # פאנל שחקן
├── styles/
│   └── main.css        # סטיילים ראשיים
├── App.tsx             # קומפוננטת האפליקציה הראשית
└── main.tsx            # נקודת הכניסה

src/                    # לוגיקת המשחק (TypeScript)
├── models/             # מודלים וממשקים
├── game/               # מנוע המשחק
├── board/              # מחולל לוח וגרף
├── managers/           # מנהלי משאבים
└── rules/              # אימות חוקים
```

## טכנולוגיות

- **React 18** - ספריית UI
- **TypeScript** - שפת תכנות מסוג type-safe
- **Vite** - build tool מהיר
- **CSS3** - עיצוב וanimations
- **SVG** - גרפיקה וקטורית ללוח המשחק

## תכונות עיצוביות

### צבעי משאבים
- 🌲 **יער (Lumber)**: ירוק כהה
- 🧱 **חומר (Brick)**: אדום-חום
- 🐑 **צמר (Wool)**: ירוק בהיר
- 🌾 **חיטה (Grain)**: זהוב
- ⛰️ **עפרות (Ore)**: אפור
- 🏜️ **מדבר (Desert)**: חום-כתום

### אנימציות
- **Fade in** בפתיחת חלון משאבים
- **Slide up** בהצגת פרטים
- **Hover effects** על כל האלמנטים האינטראקטיביים
- **Dice roll animation** בהטלת קוביות

### Responsive Design
- מתאים למסכים גדולים (1400px+)
- מתאים למסכים בינוניים (1200px-1400px)
- מתאמץ למכשירים ניידים עם פריסה אנכית
